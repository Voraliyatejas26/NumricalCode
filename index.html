NumeriCode

Numerical Methods – how computers solve maths that has no easy formula

Why Numerical Methods?

Many problems in computing (graphics, AI training, physics engines, signal processing) cannot be solved with a neat formula. Computers instead use numerical methods: step-by-step recipes that get closer and closer to the answer. This site explains every method in your syllabus with its formula, a simple meaning, and a live tool.

Types of Errors

No computer answer is perfectly exact. The error tells us how far we are from the truth. Let X = true value and X′ = approximate value.

Absolute Error Eₐ = | X − X′ |
Relative Error Eᵣ = Eₐ / | X |
Percentage Error Eₚ = Eᵣ × 100 %

In computing: floating-point numbers like 0.1 are stored approximately, so tiny errors can add up in long programs.

Solving Equations f(x) = 0

We search for the value of x where the curve crosses zero (the “root”). Each method below is a different strategy.

1. Bisection

c = (a + b) / 2

Needs f(a)·f(b) < 0. Cut the interval in half, keep the half where the sign changes. Slow but always works. Steps needed: n ≥ log₂((b−a)/ε).

2. Regula-Falsi

c = (a·f(b) − b·f(a)) / (f(b) − f(a))

Draw a straight line between (a,f(a)) and (b,f(b)); where it hits the x-axis is the next guess.

3. Newton-Raphson

xₙ₊₁ = xₙ − f(xₙ) / f′(xₙ)

Follow the tangent line down to the axis. Very fast, but needs the derivative and a good start.

4. Secant

xₙ₊₁ = xₙ − f(xₙ)(xₙ − xₙ₋₁) / (f(xₙ) − f(xₙ₋₁))

Like Newton but replaces f′ with a slope from the two latest points. No derivative needed.

In computing: calculators use Newton-Raphson for square roots; games use it for collision timing.

Solving Linear Systems A·x = b

Direct methods give the exact answer in a fixed number of steps. Iterative methods start with a guess and improve it repeatedly.

Gauss Elimination

mᵢⱼ = aᵢⱼ / aⱼⱼ , Rᵢ ← Rᵢ − mᵢⱼ·Rⱼ

Make zeros below the diagonal (upper-triangular), then back-substitute from the last row up.

Gauss-Jordan

Reduce [A | b] → [I | x]

Keep going until the left side becomes the identity matrix; the right side is the answer directly.

Jacobi Iteration

xᵢ⁽ᵏ⁺¹⁾ = ( bᵢ − Σⱼ≠ᵢ aᵢⱼ xⱼ⁽ᵏ⁾ ) / aᵢᵢ

Compute every new value using only the old round’s values.

Gauss-Seidel

xᵢ⁽ᵏ⁺¹⁾ = ( bᵢ − Σⱼ<ᵢ aᵢⱼ xⱼ⁽ᵏ⁺¹⁾ − Σⱼ>ᵢ aᵢⱼ xⱼ⁽ᵏ⁾ ) / aᵢᵢ

Same idea, but uses each new value immediately, so it usually converges faster. Both need a diagonally dominant matrix: |aᵢᵢ| > Σ|aᵢⱼ|.

In computing: PageRank, circuit simulation, 3D graphics and machine learning all solve huge linear systems.

Interpolation

You know some data points and want a value between them. Interpolation fits one smooth polynomial through all the points. Let h = spacing of x, p = (x − x₀)/h.

Newton’s Forward

y = y₀ + pΔy₀ + p(p−1)/2!·Δ²y₀ + p(p−1)(p−2)/3!·Δ³y₀ + …

p = (x − x₀)/h. Best near the start of equally spaced data.

Newton’s Backward

y = yₙ + p∇yₙ + p(p+1)/2!·∇²yₙ + p(p+1)(p+2)/3!·∇³yₙ + …

p = (x − xₙ)/h. Best near the end of the data.

Lagrange

y = Σᵢ yᵢ · Πⱼ≠ᵢ (x − xⱼ)/(xᵢ − xⱼ)

Works for unequal spacing too. Each point gets a “weight” that is 1 at itself and 0 at the others.

Newton’s Divided Difference

f[xᵢ,xᵢ₊₁] = (yᵢ₊₁ − yᵢ)/(xᵢ₊₁ − xᵢ)
y = f[x₀] + (x−x₀)f[x₀,x₁] + (x−x₀)(x−x₁)f[x₀,x₁,x₂] + …

Unequal spacing, and adding a new point only adds one new term.

In computing: image resizing, animation curves, font outlines and filling missing sensor data.

3. Regula-Falsi [c = (a·f(b) − b·f(a)) / (f(b) − f(a))]

Step 1: c = (1·4 − 2·(−2)) / (4 − (−2)) = 8/6 = 1.3333, f(c) = −0.9630 (negative, so a = 1.3333)
Step 2: c = (1.3333·4 − 2·(−0.9630)) / (4 + 0.9630) = 7.2593/4.9630 = 1.4627, f(c) = −0.3333

4. Newton-Raphson [xₙ₊₁ = xₙ − f/f′, with f′ = 3x² − 1]

x₀ = 1.5: f = −0.125, f′ = 5.75 → x₁ = 1.5 + 0.125/5.75 = 1.52174
x₁: f = 0.002188, f′ = 5.94707 → x₂ = 1.52174 − 0.000368 = 1.52137

Only 2 steps to get 4 correct decimals.

x₂ = 2 − 4(2−1)/(4−(−2)) = 1.33333, f = −0.96296
x₃ = 1.33333 − (−0.96296)(1.33333−2)/(−0.96296−4) = 1.46268, f = −0.33333
x₄ = 1.46268 − (−0.33333)(0.12935)/(−0.33333+0.96296) = 1.53116

Gauss & Jordan system: x + y + z = 6, 2x − y + z = 3, x + 2y − z = 2

6. Gauss Elimination

[1  1  1 | 6; 2 −1  1 | 3; 1  2 −1 | 2]
R₂ ← R₂ − 2R₁ : [0 −3 −1 | −9]
R₃ ← R₃ − R₁ : [0  1 −2 | −4]
R₃ ← R₃ + (1/3)R₂ : [0  0 −7/3 | −7]
Back-substitution: z = −7 ÷ (−7/3) = 3; −3y − 3 = −9 → y = 2; x + 2 + 3 = 6 → x = 1

R₂ ÷ (−3) : [0 1 1/3 | 3]; R₃ × (−3/7) : [0 0 1 | 3]
R₁ ← R₁ − R₂ : [1 0 2/3 | 3]
R₁ ← R₁ − (2/3)R₃ and R₂ ← R₂ − (1/3)R₃

Interpolation

Data for Newton: x = 1, 2, 3, 4 and y = 1, 8, 27, 64 (this is y = x³). Differences: Δy = 7, 19, 37; Δ²y = 12, 18; Δ³y = 6.

10a. Newton Forward, find y(1.5): h = 1, p = (1.5 − 1)/1 = 0.5

y = 1 + (0.5)(7) + [(0.5)(−0.5)/2!](12) + [(0.5)(−0.5)(−1.5)/3!](6)
= 1 + 3.5 − 1.5 + 0.375 = 3.375 ✓ (1.5³)

10b. Newton Backward, find y(3.5): xₙ = 4, p = (3.5 − 4)/1 = −0.5

y = 64 + (−0.5)(37) + [(−0.5)(0.5)/2!](18) + [(−0.5)(0.5)(1.5)/3!](6)
= 64 − 18.5 − 2.25 − 0.375 = 42.875 ✓ (3.5³)

Unequal spacing: points (1, 1), (2, 8), (4, 64). Find y(3).

11. Lagrange

L₀ = (3−2)(3−4) / ((1−2)(1−4)) = −1/3
L₁ = (3−1)(3−4) / ((2−1)(2−4)) = 1
L₂ = (3−1)(3−2) / ((4−1)(4−2)) = 1/3
y = 1(−1/3) + 8(1) + 64(1/3) = 29

12. Newton’s Divided Difference

f[1,2] = (8−1)/(2−1) = 7   f[2,4] = (64−8)/(4−2) = 28
f[1,2,4] = (28 − 7)/(4 − 1) = 7
y(3) = 1 + (3−1)(7) + (3−1)(3−2)(7) = 1 + 14 + 14 = 29

Lagrange and Divided Difference give the same 29 because they build the same polynomial. It is not exactly 27 because only 3 points were used.
